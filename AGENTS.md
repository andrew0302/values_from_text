# AGENTS.md

This file defines the rules and context for any AI agent working in this repository.

## What this repo is
A PhD dissertation project analysing values extracted from song lyrics and political 
speeches. Analysis is in R; documents are written in LaTeX (on Overleaf, not here).

## Folder structure
- `_data/` — input and intermediary data. Do not delete anything here.
- `_notebooks/` — R notebooks (.qmd and .Rmd). This is the primary working area.
- `_manuscript/` — scheduled for archiving, do not touch
- `images/` — plots generated by notebooks. Can be overwritten by re-rendering.
- `tables/` — LaTeX tables generated by notebooks. Can be overwritten by re-rendering.
- `archive/` — old material. Do not touch.

## What agents may do
- Edit existing notebooks in `_notebooks/` when explicitly instructed
- Create new code chunks within existing notebooks
- Rename or reorganise files within `_notebooks/` when explicitly instructed
- Render notebooks using `quarto render <file>` or `rmarkdown::render("<file>")` 
  as appropriate for the file type (.qmd or .Rmd respectively)

## What agents must not do
- Delete any file (move to `archive/` instead)
- Modify anything in `_data/`
- Modify anything in `_manuscript/`
- Make analytical decisions (e.g. model specification, what to cut) without explicit instruction
- Push to git without explicit instruction

## Notebooks: current status
- `_notebooks/participant/` — active, in use
- `_notebooks/machine/` — status uncertain, do not modify without instruction
- `_notebooks/text/` — active, in use

These may be merged into a single folder into the future

## Before making any change
1. State what you plan to do and why
2. Wait for confirmation before proceeding
